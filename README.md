## Project Overview

This project analysed business and system requirements for a healthcare mobile platform and translated them into structured process and system models.

The work focused on understanding business requirements, actors, system interactions, business rules, workflow behaviour and exception scenarios before representing the proposed solution through BPMN and UML artefacts.

Key deliverables included:

- Business and system requirements
- Actor and stakeholder analysis
- Use cases and use-case descriptions
- Business rules
- BPMN process modelling
- UML sequence modelling
- Domain/class modelling
- Exception and alternative process flows

The analytical approach followed:

**Business Need → Requirements → Actors & Use Cases → Business Rules → Process Analysis → BPMN → System Interactions → UML Models → Solution Definition**
